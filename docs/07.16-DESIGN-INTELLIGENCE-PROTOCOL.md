# PHASE 07.16+ — MANDATORY DESIGN INTELLIGENCE & UI/UX TOOLING PROTOCOL

> **Status**: FROZEN / ACTIVE MANDATE  
> **Scope**: All Frontend / UI / UX surfaces, redesigns, and components in Nexora (Phase 07.16 onwards)  
> **Guiding Principle**: *Human-directed design amplified by AI tooling — never AI-generated website slop.*

## 2. Component Library Governance & Hierarchy

All UI surfaces must strictly adhere to the following priority order:
1. **Existing Nexora Design System Primitives & Tokens** (`src/index.css`, core CSS variables, typography tokens)
2. **Existing Nexora UI Components** (`src/components/ui/*`, `Button`, `Modal`, `Input`, `Badge`, etc.)
3. **Native React & Vanilla CSS** (Tailored, accessible, performant implementations)
4. **Unlumen UI** (Selective, audited integration only when solving a concrete UX problem)
5. **SmoothUI** (Selective, audited integration only when primitives cannot achieve the UX goal)

*External component libraries are ingredients, never the visual identity.*

---

## 3. Strict "No AI-Slop" Design Prohibitions

Unless backed by an extraordinary, documented UX justification, the following are strictly prohibited:
- ❌ Purple / blue / rainbow gradient backgrounds
- ❌ Glowing borders, neon UI accents, floating gradient blobs
- ❌ Excessive glassmorphism, floating blur cards
- ❌ Nested cards inside cards without semantic hierarchy
- ❌ Generic SaaS dashboards / "AI startup" template aesthetics
- ❌ Purposeless oversized hero sections
- ❌ Meaningless 3D models, decorative particles, cursor-following canvas effects
- ❌ Excessive spring physics, bounce animations, infinite decorative loops
- ❌ Pill-heavy UI, decorative badges on every heading, arbitrary gradient text

**Nexora Core Aesthetic Identity:**
- **Editorial**: High-craft typographic hierarchy, intentional white space, disciplined line heights.
- **Architectural**: Structured grids, hairline borders, monolithic proportions, tactile materiality.
- **Premium Commerce**: High-contrast legibility, friction-free purchasing, purposeful motion, human-curated feel.

## 4. Standard 8-Step UI/UX Engineering Loop

```
1. UNDERSTAND (PRD, TRD, Design Brief, Schema, Design System)
      ↓
2. DESIGN RESEARCH (UI/UX Pro Max + Taste + Design Prompts)
      ↓
3. DESIGN SYSTEM DECISION (Tokens, Typography, Grid, States, Motion)
      ↓
4. IMPLEMENT (Nexora Primitives first, Semantic HTML, CSS Variables)
      ↓
5. INTERACTION REFINEMENT (Emil Kowalski motion principles, A11y, Focus)
      ↓
6. ANTI-SLOP REVIEW (/impeccable critique & /impeccable audit)
      ↓
7. BROWSER ITERATION (Tested at 390px, 430px, 768px, 1024px, 1280px, 1440px)
      ↓
8. FINAL POLISH (/impeccable polish + "Decoration Stripping Test")
```

> **The Decoration Stripping Test:**
> *"Would this interface still look intentional, authoritative, and elegant if all animations, gradients, shadows, and decorative effects were removed?"*  
> If no: the design relies too heavily on superficial decoration and must be refined.

## 5. Mandatory Phase Implementation Report Artifacts

Every UI/UX implementation report for Phase 07.16+ must include:

1. **Design Research Used**: Exact tools and methods actually executed (Impeccable, UI/UX Pro Max, Taste, Emil Kowalski, etc.).
2. **Design Decisions**: Concrete documentation of patterns researched, selected, rejected, and rationale.
3. **Anti-Slop Evidence**: Critique & audit findings, detected anti-patterns, and explicit remediation steps.
4. **Browser Verification Evidence**: Multi-viewport test results (390px, 430px, 768px, 1024px, 1280px, 1440px), responsive behavior, and accessibility audit notes.

---

## 6. Final Quality Gate Checklist

A UI/UX phase is only marked `🟢 COMPLETED / VERIFIED / APPROVED` when:
- [ ] Approved design resources were actively utilized.
- [ ] Design research was evaluated against the frozen Nexora Design Brief.
- [ ] Existing Nexora design tokens and primitives were preserved and extended cleanly.
- [ ] Emil Kowalski interaction principles applied with strict `prefers-reduced-motion` support.
- [ ] Impeccable critique and audit gates passed with zero unaddressed anti-slop findings.
- [ ] Real multi-viewport browser visual inspection conducted across mobile, tablet, and desktop.
- [ ] At least one iterative critique-refinement cycle completed.
- [ ] Accessibility (WCAG 2.1 AA, ARIA landmarks, keyboard focus rings, touch targets >= 44px) verified.
- [ ] Zero backend contract alterations or unrelated architectural mutations introduced.
